PROJETO ACADÊMICO

DevOps na prática

Integração contínua, testes automatizados e publicação com GitHub Actions.

Sobre o projeto

Este site demonstra um fluxo simples de desenvolvimento com Git, GitHub, CI/CD e GitHub Pages.

Etapas da pipeline

  1. Validar a estrutura do HTML e a sintaxe do CSS.
  2. Executar os testes automatizados.
  3. Publicar o site depois do merge na branch main.

Tecnologias

  • HTML5 e CSS3
  • Git e GitHub
  • GitHub Actions
  • GitHub Pages
  • Node.js para validação e testes

Projeto acadêmico de Cultura e Práticas DevOps.
