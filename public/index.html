DevOps na prática

Integração contínua, testes automatizados, segurança e publicação com GitHub Actions.

Sobre o projeto

Este site demonstra um fluxo de desenvolvimento com Git, GitHub, GitFlow, CI/CD e GitHub Pages.

Etapas da pipeline

  1. Validar a estrutura do HTML e a sintaxe do CSS.
  2. Executar os testes automatizados.
  3. Executar as análises de segurança SAST e DAST.
  4. Publicar o site depois das validações e do merge na branch main.

Segurança integrada — DevSecOps

  • SAST — CodeQL: analisa o código-fonte JavaScript para identificar padrões de vulnerabilidade.
  • DAST — OWASP ZAP: verifica o site em execução por meio de uma varredura dinâmica baseline.
  • As etapas de segurança precisam passar antes da publicação.

Tecnologias

  • HTML5 e CSS3
  • Git e GitHub com GitFlow
  • GitHub Actions e GitHub Pages
  • Node.js para validação e testes automatizados
  • CodeQL (SAST) e OWASP ZAP (DAST)
